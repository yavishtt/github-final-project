# github-final-project

## Simple Interest Calculator

A Bash calculator that computes simple interest from the principal amount,
annual interest rate (as a percentage), and time period in years.

## Inputs and output

- **Principal (p):** the starting amount of money.
- **Annual rate (r):** the interest rate as a percentage, such as 5 for 5%.
- **Time (t):** the duration in years.
- **Output:** simple interest, calculated as `p * r * t / 100`.

For example, a principal of 1000 at 5% per year for 2 years earns 100 in interest.

## Run on macOS

Open Terminal in the repository folder and run:

```bash
bash simple-interest.sh
```

Enter the principal, annual rate, and time when prompted.
The script accepts non-negative whole numbers or decimals and displays interest to two decimal places.
This is an educational example, not a production financial calculator.
